# BETTING DERBY 🏇

ブラウザだけで遊べる馬券購入シミュレーションゲームです。フレームワーク不要、`index.html` を開くだけで動作します。

## 遊び方

1. `index.html` をブラウザで開くと、まずロビー画面が表示されます。4つのモードから選んでスタートします。
   - **一般人モード**: 所持金1万円からスタートする通常モード。
   - **ギャンブラーモード**: 所持金1万円から10万円到達を目指す、何レースで達成できるかのアタックモード。
   - **ギャンブラーモードHARD**: 所持金1万円から100万円到達を目指す超高難度アタックモード。
   - **資金無限モード**: 所持金を気にせず馬券を買い放題の検証モード。回収率・的中率を計測できます。
   - 画面右上の「🏠 ロビー」でいつでもロビーに戻り、モードを選び直せます（所持金・レース数はリセットされます）。
2. 出走表には各馬の騎手・騎手ランク（S/A/B/C）・近3走の着順・調子（↗️絶好調 / ➡️普通 / ↘️不調）が表示されます。これらはオッズにも反映されており、読み解くことで「オッズ妙味」（本来の実力に対してオッズが甘い馬）を狙えます。
3. 馬を選び、式別（単勝 / 複勝 / 馬連）と金額を指定して「馬券購入」を押します。
   - **単勝**: 1着を当てると的中
   - **複勝**: 3着以内なら的中（配当は単勝より低め）
   - **馬連**: 2頭を選び、1・2着を着順不問で当てると的中（選択中の組み合わせの予想オッズが購入前に表示され、レース後は的中・不的中に関わらず購入履歴にオッズが表示されます）
4. 同じレース内であれば複数の馬券を購入できます。所持金を全額賭けてもレースはそのまま最後まで観戦できます。
5. 馬券を買わずに「馬券を買わず観戦」でレースの結果だけを見ることもできます。
6. 「レーススタート」で楕円コースを馬たちが走るレース（約25秒）をシミュレートし、結果に応じて払戻が所持金に反映されます。「スキップ」ですぐに結果を確定できます。レース結果表示の下には、自分が購入した馬が実際に何着だったかも表示されます。
7. 「次のレースへ」で新しい出走馬・オッズが生成され、次のレースに進みます。1日は12レース制で、第12レースの次は第1レースに戻ります。
8. 所持金が最低購入額（100円）を下回った状態で次のレースに進もうとするとゲームオーバーとなり、「ゲームをリスタート」で同じモードのまま最初からやり直せます（資金無限モードにゲームオーバーはありません）。

## レース番号とクラス

第1〜12レースにはそれぞれクラスが設定されています。

| レース | クラス |
| --- | --- |
| 1〜5R | 未勝利 |
| 6〜7R | 1勝クラス |
| 8〜9R | 2勝クラス |
| 10R | 3勝クラス |
| 11R | オープン |
| 12R | 1勝クラス |

未勝利戦はクラスが上がるレースに比べて実力どおりに決まらない波乱（穴馬の激走）が起きやすく設定されています。

## 天候・馬場状態

- レースごとに20%の確率で雨天となり、馬場状態が「良馬場」から「重馬場」に変わります。馬場状態はレース画面の左上に表示されます。
- 重馬場になると、B・Cランクの騎手の実際の走り（真の強さ）が上方補正されます。ただしオッズにはこの効果が十分に織り込まれないため、重馬場で下位ランクの騎手が乗る馬に「妙味」が生まれやすくなります。

## コースの見た目

- 馬場状態表示の隣にあるボタンで、コースの見た目を「ダート」と「芝」にいつでも切り替えられます（勝敗やオッズには影響しません）。
- レースが始まると、外枠の馬ほど大きくインコース側へ寄っていく、実際の競馬のような動きを再現しています。番号の視認性を保つため、寄せすぎず適度な間隔を保ったまま内側のレーンへ収束します。

## 脚質とペース

- 各馬には脚質（逃げ／先行／差し／追込）が設定されており、出走表に色分けされたマーク（逃・先・差・追）で表示されます。
- 脚質はあくまで基本の傾向で、必ずしもそのとおりに運ぶとは限りません。毎レースごとにブレがあり、先行馬が下がったり、差し馬が前に行ったりすることもあります。
- このレースで実際に先頭集団を争う頭数が多いほどハイペースになりやすく、先行系の馬が終盤バテて差し・追込馬が台頭します。逆に先頭を争う馬が少ないとスローペースになり、残った先行馬が有利になって人気薄の逃げ切りが起きやすくなります。予想以上にハイペース／スローペースになることもあるため、脚質構成を読んでも展開が外れることがあります。
- レース結果には「展開: 🔥ハイペース／◻️ミドルペース／🐌スローペース」が表示され、どんな展開だったかを振り返れます。

## オッズの仕組み

- 単勝オッズはパリミュチュエル方式を簡易的に再現しており、1頭の勝率（人気）が高いほど他の馬のオッズは自動的に高くなります。単勝オッズの範囲は1.5〜120倍で、1桁オッズ（10倍未満）の馬は1レースにつき最大5頭までに制限されています。
- 表示されるオッズは「世間の予想」に基づくもので、騎手のランクを過大評価し、馬の調子の変化を過小評価する傾向があります。実際のレース結果を左右する「真の強さ」は調子や近3走、馬場適性をより正直に反映するため、オッズと実力に意図的なズレを設けています。
- 騎手ランクはS（黄）・A（赤）・B（緑）・C（グレー）で色分け表示されます。

## 特別な馬

- **ハートビート**: 20レースに1回ほど出走する、単勝20倍以上の大穴。見た目や演出は他の馬と同じですが、出走すると必ず1着でゴールします。
- **フロンティア**: 10レースに1回ほど出走する馬。見た目や演出は他の馬と同じですが、出走すると必ず4着でゴールします。

## 特別な騎手

- 通常の騎手に加えて、J.モレイラ（Sランク・出現率18レースに1回程度）とF.デットーリ（Sランク・出現率50レースに1回程度）がごく稀に出走します。

## ファイル構成

- `index.html` — 画面構成（ロビー・レース画面）
- `style.css` — スタイル
- `script.js` — ゲームロジック（オッズ計算・レース抽選・払戻計算・アニメーション・モード管理）
