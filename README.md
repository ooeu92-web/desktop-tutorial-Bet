# 馬券購入シミュレーター 🏇

ブラウザだけで遊べる馬券購入シミュレーションゲームです。フレームワーク不要、`index.html` を開くだけで動作します。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 出走表には各馬の騎手・騎手ランク（S/A/B/C）・近3走の着順・調子（↗️絶好調 / ➡️普通 / ↘️不調）が表示されます。これらはオッズにも反映されており、読み解くことで「オッズ妙味」（本来の実力に対してオッズが甘い馬）を狙えます。
3. 馬を選び、式別（単勝 / 複勝）と金額を指定して「馬券購入」を押します。
   - **単勝**: 1着を当てると的中
   - **複勝**: 3着以内なら的中（配当は単勝より低め）
4. 同じレース内であれば複数の馬券を購入できます。所持金を全額賭けてもレースはそのまま最後まで観戦できます。
5. 「レーススタート」で楕円コースを馬たちが走るレースをシミュレートし、結果に応じて払戻が所持金に反映されます。
6. 「次のレースへ」で新しい出走馬・オッズが生成され、次のレースに進みます。
7. 所持金が最低購入額（100円）を下回った状態で次のレースに進もうとするとゲームオーバーとなり、「ゲームをリスタート」で最初からやり直せます。

## オッズの仕組み

- 単勝オッズはパリミュチュエル方式を簡易的に再現しており、1頭の勝率（人気）が高いほど他の馬のオッズは自動的に高くなります。単勝オッズの範囲は1.5〜120倍です。
- 表示されるオッズは「世間の予想」に基づくもので、騎手のランクを過大評価し、馬の調子の変化を過小評価する傾向があります。実際のレース結果を左右する「真の強さ」は調子や近3走をより正直に反映するため、オッズと実力に意図的なズレを設けています。

## ファイル構成

- `index.html` — 画面構成
- `style.css` — スタイル
- `script.js` — ゲームロジック（オッズ計算・レース抽選・払戻計算・アニメーション）
