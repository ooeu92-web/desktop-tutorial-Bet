# BETTING DERBY 🏇

ブラウザだけで遊べる馬券購入シミュレーションゲームです。フレームワーク不要、`index.html` を開くだけで動作します。

## 遊び方

1. `index.html` をブラウザで開くと、まずロビー画面が表示されます。4つのモードから選んでスタートします。
   - **一般人モード**: 所持金1万円からスタートする通常モード。
   - **ギャンブラーモード**: 所持金1万円から10万円到達を目指す、何レースで達成できるかのアタックモード。
   - **資金無限モード**: 所持金を気にせず馬券を買い放題の検証モード。回収率・的中率を計測できます。
   - **馬主モード**: 自分の馬を作り、新馬から重賞制覇を目指す特別モード（詳細は下記）。
   - 画面右上の「🏠 ロビー」でいつでもロビーに戻り、モードを選び直せます（所持金・レース数はリセットされます）。
   - 一度でもプレイすると自動的に保存され、次回開いたときにロビー画面の「▶ 続きから再開」で続きから遊べます（馬主モードは専用のセーブ枠を持ち、いつ再訪しても続きから遊べます）。セーブがある場合は「🆕 最初から始める（セーブ削除）」ボタンも表示され、通常モード・馬主モード両方のセーブを削除して完全に最初からやり直せます。
2. 画面右上の「🌙 ダーク／☀️ ライト」ボタンでテーマを切り替えられます。設定は保存され、次回も引き継がれます。
3. 出走表には各馬の騎手・騎手ランク（S/A/B/C）・近3走の着順・脚質・調子が表示されます。これらはオッズにも反映されており、読み解くことで「オッズ妙味」（本来の実力に対してオッズが甘い馬）を狙えます。
4. 出走表の上には「レーススタート」「馬券を買わず観戦」「直線までスキップ」「結果までスキップ」「次のレースへ」のレース進行ボタンをまとめて配置しています。出走表を見ながらでも操作しやすいレイアウトです。
5. 馬を選び、式別（単勝 / 複勝 / 馬連）と金額を指定して「馬券購入」を押します。
   - **単勝**: 1着を当てると的中
   - **複勝**: 3着以内なら的中（配当は単勝より低め）
   - **馬連**: 2頭を選び、1・2着を着順不問で当てると的中（選択中の組み合わせの予想オッズが購入前に表示され、レース後は的中・不的中に関わらず購入履歴にオッズが表示されます）
6. 同じレース内であれば複数の馬券を購入できます。所持金を全額賭けてもレースはそのまま最後まで観戦できます。
7. 馬券を買わずに「馬券を買わず観戦」でレースの結果だけを見ることもできます。
8. 「レーススタート」で楕円コースを馬たちが走るレース（約30秒）をシミュレートし、結果に応じて払戻が所持金に反映されます。レース中は実況テキストが展開に合わせて流れ、直線に入るとカメラがズームインして迫力ある映像になります。
   - 「直線までスキップ」は序盤〜中盤を早送りし、直線（ホームストレート）からの攻防だけを通常速度で見せます。
   - 「結果までスキップ」はレースをすぐに結果確定まで進めます。
   - レース結果表示の下には、自分が購入した馬が実際に何着だったかも表示されます。
9. 「次のレースへ」で新しい出走馬・オッズが生成され、次のレースに進みます。1日は12レース制で、第12レースの次は第1レースに戻ります。
10. 所持金が最低購入額（100円）を下回った状態で次のレースに進もうとするとゲームオーバーとなり、「ゲームをリスタート」で同じモードのまま最初からやり直せます（資金無限モードにゲームオーバーはありません）。
11. 一般人モード・ギャンブラーモード・資金無限モードのいずれでも、画面上部に回収率・的中率が常時表示されます。

## レース番号とクラス

第1〜12レースにはそれぞれクラスが設定されています。

| レース | クラス |
| --- | --- |
| 1〜5R | 未勝利 |
| 6〜7R | 1勝クラス |
| 8〜9R | 2勝クラス |
| 10R | 3勝クラス |
| 11R | オープン |
| 12R | 1勝クラス |

未勝利戦はクラスが上がるレースに比べて実力どおりに決まらない波乱（穴馬の激走）が起きやすく設定されています。

## 天候・馬場状態

- レースごとに20%の確率で雨天となり、馬場状態が「良馬場」から「重馬場」に変わります。馬場状態はレース画面の左上に表示されます。
- 重馬場になると、B・Cランクの騎手の実際の走り（真の強さ）が上方補正されます。ただしオッズにはこの効果が十分に織り込まれないため、重馬場で下位ランクの騎手が乗る馬に「妙味」が生まれやすくなります。

## コースの見た目

- 馬場状態表示の隣にあるボタンで、コースの見た目を「ダート」と「芝」にいつでも切り替えられます（勝敗やオッズには影響しません）。
- レースが始まると、外枠の馬ほど大きくインコース側へ寄っていく、実際の競馬のような動きを再現しています。番号の視認性を保つため、寄せすぎず適度な間隔を保ったまま内側のレーンへ収束します。
- 直線（ホームストレート）に入るとカメラが自動でズームインし、ゴール前の攻防を迫力ある映像で見ることができます。

## 脚質とペース

- 各馬には脚質（逃げ／先行／差し／追込）が設定されており、出走表に色分けされたマーク（逃・先・差・追）で表示されます。
- 脚質はあくまで基本の傾向で、必ずしもそのとおりに運ぶとは限りません。毎レースごとにブレがあり、先行馬が下がったり、差し馬が前に行ったりすることもあります。
- このレースで実際に先頭集団を争う頭数が多いほどハイペースになりやすく、先行系の馬が終盤バテて差し・追込馬が台頭します。逆に先頭を争う馬が少ないとスローペースになり、残った先行馬が有利になって人気薄の逃げ切りが起きやすくなります。予想以上にハイペース／スローペースになることもあるため、脚質構成を読んでも展開が外れることがあります。
- レース結果には「展開: ハイペース／ミドルペース／スローペース」が表示され、どんな展開だったかを振り返れます。
- レース中盤には実際にそのレースで先頭集団にいた馬・展開の実況が、終盤にはその馬が実際に先頭集団にいたかどうかに基づいて「粘っているか」「差してきたか」の実況が流れます（見た目の展開と実況が食い違わないようにしています）。

## オッズの仕組み

- 単勝オッズはパリミュチュエル方式を簡易的に再現しており、1頭の勝率（人気）が高いほど他の馬のオッズは自動的に高くなります。単勝オッズの範囲は1.5〜120倍で、1桁オッズ（10倍未満）の馬は1レースにつき最大5頭までに制限されています。
- 複勝オッズ（3着以内で的中）は単勝オッズより控えめな倍率になるように調整されています。的中しやすい分、配当は単勝ほど大きくは伸びません。
- 表示されるオッズは「世間の予想」に基づくもので、騎手のランクを過大評価し、馬の調子の変化を過小評価する傾向があります。実際のレース結果を左右する「真の強さ」は調子や近3走、馬場適性をより正直に反映するため、オッズと実力に意図的なズレを設けています。
- 騎手ランクはS（黄）・A（赤）・B（緑）・C（グレー）で色分け表示されます。

## 特別な馬

- **ハートビート**: 20レースに1回ほど出走する、単勝20倍以上の大穴。見た目や演出は他の馬と同じですが、出走すると必ず1着でゴールします。
- **フロンティア**: 10レースに1回ほど出走する馬。見た目や演出は他の馬と同じですが、出走すると必ず4着でゴールします。

## 特別な騎手

- 通常の騎手に加えて、J.モレイラ（Sランク・出現率18レースに1回程度）とF.デットーリ（Sランク・出現率50レースに1回程度）がごく稀に出走します。

## 馬主モード

自分だけの馬を育て、新馬（未勝利）→1勝クラス→2勝クラス→3勝クラス→オープン→重賞→GIの制覇を目指す特別モードです。通貨は円ではなく「オーナーポイント（OP）」を使います。専用のテーマ（紫・えんじ・金の配色）で他モードと見た目が区別され、トラック上でも自分の馬の番号だけ色が異なるので一目で追いかけられます。

- **馬の作成**: 好きな馬名を決め、スピード・瞬発力・勝負根性の3つの能力値をスライダーで配分します。合計は常に150に固定されており（スピード・瞬発力を動かすと勝負根性が自動計算されます）、どの能力に振っても費用対効果は同じです。
  - **スピード**: 馬の絶対的な強さの指標。高いほど逃げ・先行の位置取りになりやすくなります。
  - **瞬発力**: そのレースで後方に控えた場合の追い上げ力。前に行けなかったときの保険になります。
  - **勝負根性**: レース結果の下振れを抑え、終盤に粘れるようになります（大駆けの上限には影響しません）。
- **専属騎手と依頼料**: 通常の騎手プールから1人選んで雇用します（初回雇用費はランクが高いほど高額：S 800／A 400／B 160／C 50OP）。さらに、騎手ランクに応じた依頼料が1レースごとに固定費として所持OPから引かれます（S 200／A 100／B 40／C 15OP）。高ランクの騎手ほど強い分、維持コストも重くのしかかる、緊張感のある収支バランスにしています。
- **近3走**: 自分の馬の近3走は演出ではなく、実際にその馬が過去に走った着順がそのまま表示されます。まだ走っていない分は「-」と表示されます。
- **クラス昇格とGI**: 勝つと1クラス昇級します。重賞を2勝するとGIに挑戦できるようになり、GIで勝てば殿堂入り（完全クリア）です。GIレースに限り、すべての騎手の実際の腕前がAランク以上に引き上げられます（Sランクの騎手はそのまま）。ただしオッズにはこの効果が織り込まれないため、GIでは普段以上に「妙味」のある馬を見つけやすくなります。
- **1着賞金**: 自分の馬が1着になると、クラスに応じた賞金がその場でOPに加算されます。
  | クラス | 賞金 |
  | --- | --- |
  | 未勝利／1勝クラス | 50OP |
  | 2勝クラス／3勝クラス | 100OP |
  | オープン | 150OP |
  | 重賞 | 200OP |
  | GI | 500OP |
- **馬券購入の上限**: 馬主モードでは1回の購入額は300OPまでです。アイテムショップの「資金限度アップ」（50OP）を使うと、次のレースだけ上限が500OPに上がります。
- **厩舎（🐴）画面**: 画面右上の「🐴 厩舎」から、能力値・クラス・通算成績に加えて、
  - **騎手変更**: 依頼料を確認しながら、いつでも専属騎手を乗り換えられます。
  - **戦績**: 直近10走の着順を振り返れます。
  - **アイテムショップ**: OPを消費して「絶好調ドリンク」（次のレースで愛馬を必ず絶好調にする）や「資金限度アップ」（次のレースだけ購入上限を500OPに引き上げる）を購入できます。
  - **🏪 馬市場**: OPを消費して、能力値があらかじめ仕上がったC〜Sランクの馬を購入できます。購入すると現在の馬と入れ替わりますが、専属騎手と所持OPはそのまま引き継がれます。
  を確認・利用できます。
- レースでは自分の馬にのみ単勝・複勝で賭けられます（馬連は馬主モードでは選べません）。
- 所持OPが最低購入額を下回るとゲームオーバー（OPも馬も最初からやり直し）。クラス昇級が難しくなった場合は「🐴 厩舎」からいつでも馬を引退させ、所持OPを引き継いだまま新しい馬を作り直せます。

## スマホでのプレイ

- レイアウトはスマホ幅でも横スクロールが出ないように調整されており、出走表・購入履歴はテーブル部分だけが横スクロールする作りになっています。
- ボタンは指でタップしやすいよう十分な高さを確保しています。
- レースアニメーション（CSS Motion Path / `offset-path`）は最新のモバイルブラウザ（Android Chrome・iOS Safari 16以降）で問題なく動作します。非常に古いブラウザでは対応していない場合がありますが、現在使われているスマホであれば基本的に問題ありません。

## ホーム画面に追加（PWA）

このゲームはPWA（Progressive Web App）対応しており、スマホのホーム画面にアイコンを追加してアプリのように起動できます。

- **Android（Chrome）**: メニューから「ホーム画面に追加」または「アプリをインストール」を選択
- **iPhone（Safari）**: 共有ボタンから「ホーム画面に追加」を選択

一度読み込むとアプリ本体（HTML/CSS/JS・アイコン）がキャッシュされるため、通信が不安定な環境やオフラインでも起動・プレイできます（セーブデータはブラウザのlocalStorageに保存されるため、キャッシュとは別に保持されます）。

## ファイル構成

- `index.html` — 画面構成（ロビー・レース画面）
- `style.css` — スタイル（ライト／ダークテーマ対応）
- `script.js` — ゲームロジック（オッズ計算・レース抽選・払戻計算・アニメーション・モード管理・セーブ機能）
- `manifest.json` — PWA用のアプリ情報（アイコン・テーマカラーなど）
- `service-worker.js` — オフライン再生のためのキャッシュ処理
- `icons/` — ホーム画面アイコン画像
